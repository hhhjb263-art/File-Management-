# 2026-10-14 工作日志

## 云匣 CloudVault 代码结构与接口分析（全项目通读）

**产出**：`output/云匣CloudVault-代码结构与接口分析报告.md`

**关键结论（后续会话可直接复用）**

- 仓库并存三套形态：`server/`（C++17 Linux/POSIX + SQLite3，零第三方依赖，**接口契约真相源**）、`src/`+`qml/`（Qt6 QML 正式客户端，qmake `File.pro`）、`client/`（Qt Widgets 测试客户端/能力母体，CMake）。
- 实测规模：server/src ≈7.9k 行（`app/main.cpp` 2289 行最大）、src/ ≈10.6k 行（`HttpBackend.cpp` 1452、`TransferManager.cpp` 1135）、qml/ ≈6.25k 行（30 个 qml）、client/src ≈4.0k 行（`MainWindow.cpp` 2969）；git 跟踪 183 个文件。
- 服务端 HTTP 路由共 **31 条**；鉴权规则：`users` 表非空 ⇒ 除 `/healthz` 与 `/s/*` 外强制 Bearer；`authUserId==-1` 为 legacy/admin（不过滤），`>=1` 按 `owner_id` 隔离、越权一律 404。
- 已闭环能力：整文件上传 / 分块上传（秒传 `done:true` + 断点续传 + 自愈）/ Range 并发下载 / 目录树 + 按路径访问 / 分享（提取码哈希 + 原子计数 + 软撤销 + 浏览器落地页）/ 账号会话（PBKDF2 210k 迭代，会话只存 sha256(token)，token_version 踢下线）/ 空间统计与真正回收。
- **最大落差**：PRD 第一卖点「文件夹自动双向同步」未实现 —— `src/sync/` 只有 `LocalIndex`（已实现但零引用）+ `SyncRules.h`（仅声明无 .cpp），无 FileWatcher/SyncEngine，`SyncController::supported()==false`。
- 其他高优先级问题：未启用鉴权时明文 HTTP 默认开启且仅打 WARN；删除为硬删除无回收站、`file_version` 表建而不用；两套客户端并行维护有语义漂移风险；本机 Windows 无法编译服务端 ⇒ 账号体系/越权隔离运行时行为从未实测。
- 工程约定（重要）：分块大小唯一来源 `Backend::chunkSize()`（禁止硬编码）；覆盖同名必须原子（严禁先删再传）；`statusMessage(msg,ok)` 是 toast 通道不是状态通道（内部状态用 `refreshFinished(bool)` 之类专用信号）；路由 `/api/v1/shares/cleanup` 必须注册在 `/:id` 之前；提交前必跑 `python scripts/check_build_registration.py`。
- 文档漂移：`server/README.md` 仍把账号体系列为「未实现」；`data/ShareLinkModel.*` 注释仍称「服务端不支持分享」。

## 正式 QML 客户端 UI 换肤（现代桌面效率风 + 双主题）

**方向（用户拍板）**：正式 QML 客户端（`qml/`+`src/`，qmake → `bin/CloudVault.exe`）· 现代桌面效率风（Linear/Notion 一脉）· **视觉换肤**（布局与信息架构不动）· 浅色+深色跟随系统。

**产出**：`docs/UI设计系统-现代桌面效率风.md`（含令牌表、组件规格、WCAG 对比度实测）

**关键改动**

- `qml/theme/Icons.qml`（新增单例）：35 个 24×24 线性图标路径 + **emoji→图标名映射层**，使 20+ 文件里的 `glyph: "⬆"` 等 emoji 零改动自动升级为矢量图标。`qml/controls/CvIcon.qml`（新增）用 QtQuick.Shapes 渲染（无 QtSvg 依赖）。

**环境坑（重要，下次直接复用）**
- 本机 qmake 的编译器探测在当前 Git Bash 环境**必然失败**：`Project ERROR: failed to parse default include paths from compiler output`。
- **解法**：把历史构建目录里的 qmake 缓存复制过来即可跳过探测——
  `cp build_official/.qmake.stash <新构建目录>/.qmake.stash`，再跑 qmake 就正常。
- 另外：沙箱禁止从 Bash 调用 `cmd.exe`（静态拦截，放开沙箱也拦）。

## 第二轮：字体尺度重标定 + 界面打磨 + 登录门修复

**根因发现（重要）**：`Theme.qml` 初版把 **pt 当 px** 用 —— `fontBody: 13` 在 96 DPI 下实际渲染 **17.3px**，
而控件高只有 32px，字几乎顶满按钮。这是"界面显得陈旧"的最大来源（比配色更致命）。
修正：按目标像素反推 pointSize（正文 13px → **9.75pt**），并同步收紧尺寸令牌
（控件 32→30、行高 36→34、图标 16→14、工具栏 48→44、导航栏 96→84、状态条新增 26、表头新增 30）。
字号令牌类型 int → real。**风险可控的关键**：全仓 `Theme.font*` 只出现在 `font.pointSize:` 上（脚本校验 0 例外）。

**表格现代化**：表头改为可点击排序（点同列切换升降序）+ chevron 方向指示 + hover + `PointingHandCursor`；
行加 1px `divider` 分隔线（悬停/选中行不画）；**移除永远显示 `-` 的「状态」列**（依赖服务端不返回的 `instant`，
契约 §9-L3 已记录）；右对齐表头改显式 `x: parent.width - width` 定位（不依赖 spacer 语义）。

**登录门修复（真实缺陷）**：自动弹出的登录门**没有任何关闭入口** —— 跳过按钮只在 `forced` 时可见，
而登录动作依赖后端（不可达/未配置时必然失败）→ 用户被彻底锁死。
修复：`AuthController` 新增 `loginSkipped` 属性 + `skipLogin()`/`resumeLogin()`（加法式），
`Settings` 持久化 `auth/skipLogin`，登录成功/切服务器时复位；`LoginPage` 加**常驻右上角 ✕** + **底部居中「暂不登录，继续使用访问令牌」**；
`Main.qml` 接线，并让 `loginSkipped` 时也加载文件列表。

**新增工具**：`scripts/png_probe.py` —— 纯标准库 PNG 解码器 + 墨迹区间测量，用于**像素级验证 UI 对齐**
（肉眼判断不可靠：我曾目测「大小」表头在 x≈540，实测在 733；✕ 按钮目测 1070，实测 1249）。
实测结论：表头与数据列右边界精确一致（753 vs 753）、表头带 30px、行高 34px、分隔线 #1F242C —— 与令牌完全吻合。

**验证**：编译 0 error/0 warning；门禁三条全 OK；30 个 QML qmllint 通过；
登录门两条路径均出图验证（未跳过→门显示且有出口；skipLogin=true→门消失、主界面可用）。
