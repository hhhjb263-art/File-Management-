### 0.2 用例编号

`TC-<段>-<序号>`，段位见上表。执行状态：`PASS` / `FAIL` / `NOT RUN`（含原因）。

### 0.3 断言口径

- **输入 → 预期输出**必须可机械比对（字符串 / 数字 / HTTP 状态码 / JSON 字段）。
- 服务端一切时间字段落库为 **Unix 毫秒**；对外 ISO-8601 为 `isotime::fromMillis()` 转换后结果。
- 身份语义冻结：`authUserId = -1` 不过滤；`>=1` 只允许 `owner_id == authUserId`，越权一律 **404**。

## §B 密码学层

### B.1 PBKDF2-HMAC-SHA256（`server/src/core/pbkdf2.cpp`）

采用**公开标准向量**（P="password"，S="salt"）：

| 编号 | 输入 | 预期输出（hex） |
|---|---|---|
| TC-B-01 | `c=1, dkLen=32` | `120fb6cffcf8b32c43e7225256c4f837a86548c92ccc35480805987cb70be17b` |
| TC-B-02 | `c=2, dkLen=32` | `ae4d0c95af6b46d32d0adff928f06dd02a303f8ef3c251dfd6e2d85a95474c43` |
| TC-B-03 | `c=4096, dkLen=32` | `c5e478d59288c841aa530db6845c4c8d962893a001ce4e11a4963873aa98134a` |
| TC-B-04 | `c=4096, dkLen=40` | `348c89dbcbd32b2f32d814b8116e84cf2b17347ebc1800181c4e2a1fb8dd53e1c635518c7dac47e9`（跨块 + 截断） |
| TC-B-05 | 同参数调用两次 | 结果完全相同（可复现） |
| TC-B-06 | 换盐（S="salt2"），同 P/c/dkLen | 结果 ≠ TC-B-03（**证明盐真的被使用**） |
| TC-B-07 | `constantTimeEqualHex("aa","aa")` | `true` |
| TC-B-08 | `constantTimeEqualHex("aa","ab")` | `false` |
| TC-B-09 | `constantTimeEqualHex("aa","aaa")` / `("","")` 边界 | 长度不同 → `false`（不提前 return） |

> ⚠️ 历史缺陷：曾把 hex 当二进制用于 HMAC 内部，导致 4 条向量全不过。**手写密码学必须用标准向量验证**。

| TC-B-10 | `1767225600000` | `2026-01-01T00:00:00Z` |

## §D HTTP 契约层（**需 Linux 环境执行**）

> 服务端 `net/` 用 POSIX socket，Windows 不可编译运行，故本段全部 `NOT RUN`。
> 用例可直接用 `curl` 逐条执行；`BASE` = 服务端地址。
