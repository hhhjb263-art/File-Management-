# 云匣 CloudVault 用户手册

版本 v0.5.0

---

## 1. 界面总览

顶栏：健康检查 · 传输队列（带数量徽标） · 登录/注册 或 账户菜单 · 溢出菜单（⋮）
左侧导航：**文件** · **传输** · **分享** · 标签（未支持） · 回收站（未支持） · 版本（未支持） · **设置**
右侧：文件预览面板（宽屏且停留在文件页时显示）
底部状态条：连接状态 · 剩余空间 · 传输状态

底部結果提示条（toast）会自动消失（4.5 秒）；失败提示里若含「令牌无效」，会出现【前往设置】按钮。

快捷键：

| 快捷键 | 功能 |
|---|---|
| `Ctrl+U` | 上传文件 |
| `Ctrl+D` | 下载选中项 |
| `Ctrl+L` | 打开连接设置 |
| `F5` / `Ctrl+R` | 刷新文件列表与空间 |

## 2. 连接设置

进入【设置】页，六个分区：

**① 连接服务器**
- 协议（http / https）+ 主机 IP + 端口，三段分填
- 访问令牌：填服务端 `--auth-token` 的值；服务端未启用鉴权时可留空；已登录时由会话托管
- 【保存设置】：写入本机配置并即时生效
- 【测试连接】：探活并显示服务端版本

**② 自动刷新**
- 开关 + 间隔（15 / 30 / 60 / 120 秒）
- 仅停留在「文件」页时轮询；**内容无变化不会刷新界面、也不会弹任何提示**
- 服务器不可达时自动暂停自动刷新（避免反复卡顿），手动刷新即可恢复

**③ 自签名证书与信任**
- 【允许使用自签名证书】开关
- 【查看/刷新指纹】：显示当前主机已固定的证书指纹
- 【清除该主机信任】：换证书后用它恢复连接

**④ 下载目录**：默认保存位置，【浏览】选择，改后需【保存设置】

**⑤ 本机磁盘空间**：客户端机器的磁盘容量与剩余量，可【重新扫描】

**⑥ 能力说明**：当前服务端支持的特性清单

## 3. 账号

- 服务端**没有任何账号**时是 legacy 模式：不显示登录门，用访问令牌即可使用
- 注册第一个账号后，账号体系立即启用：此后除 `/healthz` 与公开分享链接外，全部接口都需要登录会话
- 顶栏【🔑 登录 / 注册】→ 覆盖式登录页，可切换"登录 / 注册"
- 用户名：3–32 位字母数字 `._-`；密码：8–200 位
- 【记住密码】会把密码明文存在本机 `settings.ini`（桌面应用惯例，可选）
- 退出登录：顶栏账户菜单 或 溢出菜单 → 退出登录

| 提示 | 含义 |
|---|---|
| 用户名或密码错误 | 不区分"用户不存在"与"密码错"（防用户名枚举） |
| 尝试次数过多，账号已锁定 | 连续失败 5 次锁定 5 分钟，界面倒计时 |
| 账号已被禁用 | 联系管理员 |
| 登录已过期，请重新登录 | 会话失效（令牌被清），重新登录即可 |

> 每台设备的会话独立，登出只撤销本机这一条会话；改密码会让该用户全部旧会话失效。

## 4. 文件管理

### 浏览
- 双击文件夹进入；面包屑可跳回任意层级；工具栏【上一级】
- 列表列：名称 / 大小 / 修改时间 / 状态
- 右键列表头：按名称、大小、时间排序（升序 / 降序）
- 搜索框实时过滤当前目录

### 上传
三种方式：
1. 工具栏 / 右键 → 【上传文件】（快捷键 `Ctrl+U`）
2. 直接把文件拖到列表区
3. 右键空白处 → 【上传到此目录】

- 自动走**分块上传**（默认 5 MiB/块），支持**断点续传**：中断后重传同一文件，服务端告知已收分块，只补缺失部分
- **秒传**：服务端已存在相同内容（SHA-256 一致）时瞬间完成，列表状态显示「秒传」
- **同名冲突**：弹框询问【覆盖】/【跳过】（跳过是安全默认）。覆盖是服务端**原子替换**，绝不会"先删后传"

### 下载
选中一行或多行 → 工具栏 / 右键 → 【下载】（`Ctrl+D`），保存到"下载目录"并 supports Range 分段续传。

### 新建 / 重命名 / 删除
- 右键 → 【新建文件】/【新建文件夹】（文件夹支持 `a/b` 一次建多级）
- 右键 → 【重命名】：同名会报错
- 右键 → 【删除】：⚠️ **服务端没有回收站，删除是真实永久删除且不可恢复**，需二次确认

## 5. 文件预览

选中文件后右侧自动预览（宽屏在文件页显示）。支持：

- **文本**：等宽只读，超长换行不撑破布局
- **图片**：按扩展名直接渲染
- **文件夹**：显示基本信息而非内容
- 其他类型：提示不支持预览

预览只读取文件头部一小段（走异步 Range），不会把整个大文件拉到本机，也不会卡住界面。

## 6. 传输队列

工具栏【传输队列】打开右侧抽屉（默认隐藏），或进入【传输】整页。

内容：
- **进行中**：实时进度、速度、取消按钮
- **已上传 / 已下载**：两个可折叠历史分组

同名冲突由统一的"覆盖询问"对话框处理，选择后自动继续或跳过。
【打开下载目录】按钮在系统文件管理器打开目标文件夹。

## 7. 分享链接

### 创建
文件页右键 → 【分享…】：
- **提取码**：留空 = 无提取码；可填或让程序生成（4–6 位字母数字）
- **有效期**：可选天数，0 = 永久
- **下载次数**：上限，0 = 不限

创建后弹出结果：链接 + 提取码 + 一键复制。
⚠️ **提取码只在创建时显示这一次**（服务端只存 `sha256(token+code)`，无法找回）。本机会把它缓存起来，因此自己创建的分享在列表里还能看到；**别的设备创建的分享看不到提取码**，显示「—」。

### 管理（【分享】页）
两栏：**进行中** / **已失效**（已撤销、已过期、次数用尽）
每条支持：复制链接、复制提取码、撤销、【一键清除无效分享】（物理删除，不可恢复）

### 接收方怎么用
浏览器直接打开链接：
- 带提取码的先输入提取码
- 校验通过后显示文件名、大小、有效期、剩余次数，点【下载】
- 过期/用尽显示明确原因文案

> 落地页本身**不消耗**下载次数，只有真正点【下载】才计数。

以下页面为占位，服务端尚未实现，**不是 bug**：

## 9. 重要限制（务必知晓）

| 限制 | 数值 / 行为 |
|---|---|
| 单次整文件上传上限 | 64 MiB（超出请走分块上传，客户端自动处理） |
| 分块大小 | 默认 5 MiB，取值范围 64 KiB ~ 64 MiB |
| 单次 Range 响应跨度 | 16 MiB（客户端自动分多段拉取） |
| 单次整文件下载上限 | 8 MiB（超出服务端要求分段，客户端自动处理） |
| 分块总量上限 | 1 TiB（sanity 上限） |
| 列表返回上限 | 最近 500 条 |
| 上传空间预检 | 文件大小 + 64 MiB 余量，不足返回 507 |
| 路径长度 | 整路径 ≤ 400 字节，单段 ≤ 128 字节（UTF-8 计） |
| 非法文件名字符 | `< > : " \| ? *`、控制字符、`/` `\`（均被拒） |
| 保留名 | `CON` `NUL` `COM1-9` `LPT1-9` 等（含 `CON.txt` 形态） |
| 会话有效期 | 7 天，滑动续期 |
| 上传会话 GC | 闲置超 24 小时自动清理 |

## 10. 常见问题

**Q：连不上服务器？**
检查服务端是否运行、端口是否放行、`--http=off` 时是否还在用 http 协议；设置页点【测试连接】看状态栏提示。

**Q：提示「令牌无效」怎么办？**
令牌与服务端 `--auth-token` 不一致。设置页重新填写保存；若服务端已启用账号体系，改用登录。

**Q：弹出「服务器证书已变更」？**
本机记录的指纹与新证书不符。若确认是**自己换了证书** → 点【清除记录并重新信任】；若没换过 → 极可能是中间人攻击，**保持拒绝**并排查网络。

**Q：上传失败说磁盘不足（507）？**
清理服务端 `<data-dir>` 所在磁盘，或把 `--data-dir` / `--files-root` 指向更大分区。

**Q：删除的文件能找回吗？**
不能。服务端无回收站，删除后 blob 会被立即回收。

**Q：同一账号在别的电脑上也能看到我的文件吗？**
能。但不同账号之间完全隔离，看不到彼此的文件；即使是文件 ID 也一律返回 404（不泄漏"该 ID 是否存在"）。

**Q：日志在哪？**
Windows：`<LocalAppData>/CloudVault/logs/cloudvault.log`
（路径由 `AppPaths::logDir()` 决定；服务端日志由 `--log-file` 指定。）

**Q：想彻底重置客户端？**
退出客户端 → 删除 `%LOCALAPPDATA%/cloudvault/CloudVault/config/settings.ini`（会清掉连接配置、令牌、**本机缓存的分享提取码**、已固定的证书指纹）。
